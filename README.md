# RupeeMind Frontend (MVP)

Ultra-premium dark-theme Next.js dashboard for RupeeMind, focused on financial control and trust.

## How to view it locally

### 1) Install dependencies

```bash
npm install
```

If you hit a `403 Forbidden` from npm registry in your environment, set the public registry explicitly and retry:

```bash
npm config set registry https://registry.npmjs.org/
npm install
```

### 2) Run development server

```bash
npm run dev
```

Open:

- `http://localhost:3000`

### 3) Production build check

```bash
npm run build
npm run start
```

## Tech stack

- Next.js 14
- React 18
- Tailwind CSS
